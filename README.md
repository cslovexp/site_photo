# 공사사진 공식 지원 페이지

공사사진의 App Store 및 앱 사용자 지원을 위한 정적 GitHub Pages 저장소입니다.

## 공개 페이지

- 서비스 안내: https://cslovexp.github.io/site_photo/
- 고객지원: https://cslovexp.github.io/site_photo/support.html
- 개인정보처리방침: https://cslovexp.github.io/site_photo/privacy-policy.html

## 파일 구성

```text
site_photo/
├── app-logo.png
├── index.html
├── privacy-policy.html
├── privacy-policy.md
├── support.html
├── styles.css
└── README.md
```

## App Store Connect 입력

```text
지원 URL:
https://cslovexp.github.io/site_photo/support.html

개인정보처리방침 URL:
https://cslovexp.github.io/site_photo/privacy-policy.html
```

## 배포

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 배포 대상으로 사용합니다.
변경 내용을 `main` 브랜치에 push한 뒤 공개 URL에서 반영 여부를 확인합니다.
