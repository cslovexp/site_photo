개인정보처리방침

공사사진은 공사 현장 사진과 보고서 데이터를 기기 안에서 처리하는 로컬 우선 앱입니다.

최종 수정일: 2026년 10월 12일

1. 처리하는 정보

앱은 자체 서버 계정, 로그인 정보, 위치 정보 또는 분석 이벤트를 수집하지 않습니다.

사용자가 직접 입력하거나 생성하는 다음 정보는 사용자 기기의 로컬 저장소에 저장됩니다.

  • 현장명, 현장 주소, 발주처·고객명, 업체명, 담당자명
  • 현장사진과 사진의 공종, 위치, 시공 단계, 메모, 촬영일
  • 점검 장소, 점검 항목과 점검 결과
  • 생성된 PDF 보고서
  • 사용자가 등록한 회사명과 회사 로고

2. 사진 및 파일 처리

카메라로 촬영하거나 앨범에서 선택한 사진은 앱 문서 디렉터리에 복사되어 저장됩니다.

생성된 PDF 보고서도 기기의 앱 문서 저장 영역에 저장됩니다.

3. 권한 사용 목적

  • 카메라: 현장사진 촬영
  • 사진 보관함: 앨범에서 현장사진 또는 회사 로고 선택
  • 파일 및 공유: 사용자가 선택한 대상으로 PDF 보고서 공유

권한은 위 기능을 수행하기 위해서만 사용됩니다.

4. 외부 전송

앱은 사진, 현장 정보와 PDF 보고서를 자체 서버로 업로드하지 않습니다.

사용자가 공유 기능을 직접 실행한 경우에만 선택한 대상 앱으로 해당 PDF 파일이 전달됩니다.

5. 결제 정보

Pro 구독 또는 구매 기능은 사용 중인 앱마켓의 결제 시스템을 통해 처리됩니다.

앱은 카드번호 등 결제 수단 정보를 직접 수집하거나 저장하지 않습니다.

6. 데이터 삭제

사용자는 앱 안에서 저장된 현장, 사진, 보고서와 점검 데이터를 삭제할 수 있습니다.

앱을 삭제하면 기기의 앱 저장 영역에 보관된 로컬 데이터도 함께 삭제됩니다.

7. 문의

개인정보 관련 문의와 지원 요청은 고객지원 페이지를 이용해 주세요.
